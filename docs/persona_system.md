# Persona System
## 目的
ユーザーごとの属性に応じて
会話内容・広告・情報提供を最適化する。
---
## ペルソナの基本構造
ペルソナは以下の情報を持つ。
```
gender
age
job
interest
tone
segment
```

例
```
{
 gender: "female",
 age: "50s",
 job: "teacher",
 interest: ["health","culture"],
 tone: "gentle",
 segment: "community"
}
```

---
## ペルソナ利用箇所
### 会話生成
AIの話し方を変更する。
例
```
男性 → ビジネス寄り
女性 → 優しい口調
```
---
### 情報提供
ユーザーに合わせた情報を提供。
例
```
女性
・今日のレシピ
・健康情報
男性
・株価
・ビジネスニュース
```
---
### 広告最適化
ユーザーの興味に基づいて広告を選択。

例
```
ワイン好き → ワインバー広告
文化好き → 三味線イベント
```
---

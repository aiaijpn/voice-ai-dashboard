# Ad Module

## 目的

AI会話の中に自然な形で広告や情報を挿入する。

---

## 広告の役割

広告は以下の3つを目的とする。

1 収益化
2 会話継続
3 コミュニティ形成

---

## 広告挿入タイミング

会話回数によって頻度を調整する。

```
1〜10回
2回に1回

11回以降
3回に1回
```

---

## 広告種類

### 1 ビジネス広告

例

```
ワインバー
法律相談
オーダースーツ
```

---

### 2 情報型広告

例

```
今日のレシピ
今日の運勢
文化情報
```

---

### 3 コミュニティ広告

例

```
三味線ファンクラブ
ビジネス交流会
AI勉強会
```

---

## 広告データ構造

例

```
{
 name: "ワインバー小澤",
 type: "business",
 category: "wine",
 message: "銀座で静かにワインを楽しめるお店です"
}
```

---

## 広告生成

AIが文章を自然に整形する。

例

```
おすすめ
銀座のワインバー小澤
落ち着いた空間でワインを楽しめます
```
